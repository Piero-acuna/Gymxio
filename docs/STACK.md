# Stack (igual que Invenxio)

| Capa | Elección |
|---|---|
| Interfaz | React 18 + Vite (JavaScript) |
| Diseño | Tailwind CSS 3, tokens `gx-*` en `tailwind.config.js` (azul marino y ámbar), fuentes DM Sans y JetBrains Mono |
| Backend | Supabase: Postgres, Auth, RLS y funciones RPC en `supabase/migrations/` |
| Serverless | Funciones de Vercel en `api/` |
| Calidad | ESLint 9, Vitest |
| Despliegue | Vercel (`vercel.json`) |

TypeScript se puede sumar después sin cambiar la estructura.
